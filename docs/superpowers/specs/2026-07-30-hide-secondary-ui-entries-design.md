# 隐藏次要界面入口设计

## 目标

以最小前端改动隐藏以下界面内容，同时保留全部路由、领域模型、Gateway、后端接口和业务实现：

- 简历编辑器右上角“生成与导出”“版本与建议”“模板设置”三个入口，以及移动端对应入口；
- 模拟面试报告的“可观察沟通指标”整栏；
- 知识库页右上角“搜索知识库”入口。

## 设计

直接在现有 JSX 元素上使用原生 `hidden` 属性。该属性使元素不参与布局、不进入可访问性树且不能接收点击或键盘焦点，同时不删除原有组件和导航代码。

简历桌面端隐藏包含三个入口的现有容器；移动端只隐藏三个对应 `Link`，保留内容、预览和简历助手切换。面试报告只隐藏指标 `section`，不改变报告数据读取。知识库只隐藏搜索 `Link`，保留上传和新建笔记入口。

## 非目标

- 不删除或修改任何路由；
- 不修改后端、契约、数据模型或 Gateway；
- 不修改 PDF 生成、面试报告生成或知识库检索能力；
- 不使用全局 CSS 选择器，不影响其他页面同名按钮。

## 验证

- 简历编辑页三个入口不可见，PDF 预览按钮仍可用；
- 面试报告不显示“可观察沟通指标”，后续“下一次练习”仍显示；
- 知识库页不显示“搜索知识库”，上传和新建手动笔记仍显示。
